# Publish Sandhya’s Ocean Blue portfolio for free

1. Extract this ZIP on your computer. Do not upload the ZIP itself.
2. Sign in to GitHub as gmsandhya19-cyber.
3. Create a public repository named exactly: gmsandhya19-cyber.github.io
4. In that repository choose Add file → Upload files.
5. Upload all extracted website files and the assets folder. index.html must appear directly in the repository root, not inside another folder. Include the portrait and favicon inside assets/.
6. Commit the upload to main.
7. Open Settings → Pages → Build and deployment.
8. Select Deploy from a branch, then main, / (root), and Save.
9. Wait for GitHub’s deployment to finish. Your intended URL is https://gmsandhya19-cyber.github.io/ (not live until you deploy).

No custom domain, API key or paid plan is required for this static public repository.
The project uses your final Ocean Blue colours. Text, projects and portrait are unchanged. Phone number is not included.
GitHub repositories load from the public GitHub API; rate limits or connectivity may temporarily affect the list. LinkedIn opens your profile.
The enquiry form prepares a draft in the visitor’s email app; it does not send messages itself.
Future GitHub repository updates can appear in the live list. Editing your portfolio’s own content still requires updating its files.

If you see a 404, confirm the exact repository name, index.html at the root, and a successful Pages deployment.
